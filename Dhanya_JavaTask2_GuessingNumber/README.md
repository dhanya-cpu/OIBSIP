## 📌 Features

* Random number generation between 1 and 100
* 3 rounds of gameplay
* Maximum 7 attempts per round
* Score calculation based on attempts used
* User-friendly console interface
* Input validation
* Running total score across rounds

## 🛠️ Technologies Used

* Java
* Object-Oriented Programming (OOP)
* Java Random Class
* Java Scanner Class

## 🚀 How to Run

### 1. Compile the Program

```bash
javac GuessTheNumber.java
```

### 2. Run the Program

```bash
java GuessTheNumber
```

## 🎮 Gameplay Rules

1. The computer generates a random number between 1 and 100.
2. The player has up to 7 attempts to guess the number.
3. Hints are provided:

   * Too LOW
   * Too HIGH
4. The game consists of 3 rounds.
5. Points are awarded based on how quickly the number is guessed.
6. The final score is displayed after all rounds.
